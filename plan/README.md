# plan/

Project planning, tracking, and roadmap documents.

- **Current work** is tracked in `PLAN.md` and `debt.md`
- **Future vision** is documented in `future.md`
- **Completed phases** are archived (moved to documentation)

## Files

| File | Purpose |
|------|---------|
| **PLAN.md** | Current status and immediate next steps (updated per session) |
| **debt.md** | Phase 4 near-term technical work (6-9 hours, production features) |
| **future.md** | Long-term strategic roadmap (post-Phase 4, vision & scaling) |
| features.md | Feature list by phase and user role (reference) |
| legacy-items-rule-migration-matrix.md | Migration guide for legacy data (reference) |

## How to Use

- **Start session:** Read `PLAN.md` for current status
- **Plan work:** Check `debt.md` for near-term tasks
- **Long-term thinking:** Review `future.md` for strategic direction
- **Feature details:** Consult `features.md` for specifications

## Document Lifecycle

✅ **Completed phases** (1-3, Domain B/C) → Removed from plan, tracked in CHANGELOG.md
📋 **Current phase** (Phase 4) → In `debt.md`
🚀 **Future phases** → In `future.md`
