# ItemComponent - Quick Start (5 minutes)\n\n## The 30-Second Version\n\nItemComponent is a **production-ready**, **reusable** item configurator that:\n- Shows items in catalog or basket mode\n- Calculates prices in real-time\n- Enforces business rules\n- Tracks user-set vs auto-calculated values\n- Looks absolutely professional\n\n## Installation (1 minute)\n\n### Step 1: Copy Files\n\n```bash\n# Copy ItemComponent files to your project\ncp ItemComponent.js your-app/components/\ncp ItemComponent.html your-app/components/\ncp Item.js your-app/components/\ncp domain/ your-app/components/\n```\n\n### Step 2: Load in Your HTML\n\n```html\n<!DOCTYPE html>\n<html>\n<head>\n  <!-- Load Alpine.js -->\n  <script src=\"https://unpkg.com/alpinejs@3.12.0/dist/cdn.min.js\" defer></script>\n  \n  <!-- Load ItemComponent -->\n  <script type=\"module\">\n    import { ItemComponent } from './components/ItemComponent.js';\n    window.ItemComponent = ItemComponent;\n  </script>\n</head>\n<body>\n  <!-- Mount component here -->\n  <div id=\"app\"></div>\n  \n  <script>\n    // Load and mount\n    fetch('./components/ItemComponent.html')\n      .then(r => r.text())\n      .then(html => {\n        document.getElementById('app').innerHTML = html;\n        Alpine.start();\n      });\n  </script>\n</body>\n</html>\n```\n\n## Usage (2 minutes)\n\n### Define Your Item\n\n```javascript\nconst myItem = {\n  id: 'ITEM_001',\n  name: 'Plated Dinner',\n  description: 'Multi-course gourmet experience',\n  category: 'Catering',\n  pricingProfile: {\n    baseFijo: 0,           // No base fee\n    porPersona: 85000,     // CLP per person\n    porUnidad: 0,\n    porMinuto: 0\n  },\n  defaultQuantities: {\n    unidadesPorUsuario: 1  // 1 unit per person\n  },\n  rules: []               // No restrictions yet\n};\n```\n\n### Create Component\n\n```javascript\nconst component = ItemComponent.create(myItem, {\n  paxGlobal: 100,         // 100 guests\n  duracionMin: 180,       // 3 hours\n  hora: '19:00',          // 7 PM\n  dia: '2026-02-28'       // Date\n});\n```\n\n### Use in HTML\n\nThe template shows both **catalog view** (click to add) and **basket view** (with details) automatically.\n\n## Common Tasks\n\n### Task 1: Update Pricing\n\n```javascript\n// User adjusts base price\ncomponent.setProfileValue('baseFijo', 50000);\n\n// Component recalculates automatically ✨\nconsole.log(component.total); // Updated total\n```\n\n### Task 2: Override Quantity\n\n```javascript\n// User manually sets guest count\ncomponent.setOverride('pax', 150);\n\n// Component tracks it as \"user-set\" (shows orange badge)\nconsole.log(component.state.isUserSetPax);  // true\nconsole.log(component.state.total);         // Recalculated\n```\n\n### Task 3: Add Business Rule\n\n```javascript\n// Create a rule: \"Max 200 guests\"\nconst rule = {\n  ID_Regla: 'MAX_GUESTS',\n  Nombre: 'Maximum 200 guests',\n  Tipo_Accion: 'ERROR',           // Blocking\n  Condicion_JSON: {\n    '>': [{ 'var': 'pax' }, 200]\n  },\n  Scope: 'ITEM',\n  Activo: true\n};\n\n// Add to component\ncomponent.newRuleForm = { /* ... rule data ... */ };\ncomponent.addRule();\n\n// If 201+ guests: error shows, item becomes unavailable\nconsole.log(component.state.ruleErrors);  // [{ message: 'Maximum 200 guests' }]\n```\n\n### Task 4: Export Data\n\n```javascript\n// Get complete component state\nconst savedState = component.toJSON();\nconsole.log(savedState);\n// {\n//   mode: 'basket',\n//   definition: { /* item */ },\n//   externalContext: { /* event */ },\n//   overrides: { pax: 150 },\n//   userSetFields: ['pax']\n// }\n\n// Send to backend, save to DB, etc.\nawait fetch('/api/items/save', {\n  method: 'POST',\n  body: JSON.stringify(savedState)\n});\n```\n\n## Component Modes\n\n### Catalog View (Default)\n\n- Shows item as a beautiful card\n- Displays pricing formula\n- Click anywhere to add to basket\n- No quantity controls\n\n### Basket View (After Adding)\n\n- Expandable accordion\n- Quantity controls (guests, units, minutes)\n- Pricing breakdown\n- Comments section\n- Delete button\n\nToggle modes:\n\n```javascript\ncomponent.addToBasket();        // Switch to basket\ncomponent.removeFromBasket();   // Back to catalog\n```\n\n## State Object Reference\n\nEverything you need to display/use:\n\n```javascript\ncomponent.state = {\n  // Display\n  mode: 'catalog' | 'basket',\n  definition: { name, category, ... },\n  \n  // Calculated\n  total: 8500000,              // Total price\n  quantities: { pax: 100, cantidad: 0, duracionMin: 0 },\n  \n  // Display strings (human-readable)\n  catalogFormulaHuman: 'CLP 85,000 per person',\n  basketLegend: 'CLP 85,000 × 100 = CLP 8,500,000',\n  \n  // User overrides\n  isUserSetPax: true,          // Manual vs auto\n  userSetFields: ['pax'],\n  \n  // Rules\n  ruleErrors: [],              // Blocking rules\n  ruleWarnings: [],            // Caution rules\n  available: true,             // Can add to basket?\n  \n  // Form state\n  comentarios: 'Special request...',\n  schedule: { dia: '2026-02-28', hora: '19:00' }\n}\n```\n\n## Styling\n\nThe component comes with beautiful CSS that matches a professional luxury aesthetic.\n\nCustomize via CSS variables:\n\n```css\n:root {\n  --color-navy: #1a1f3a;      /* ItemComponent:\n\n```html\n<script src=\"https://unpkg.com/alpinejs@3.12.0/dist/cdn.min.js\" defer></script>\n<script type=\"module\">import { ItemComponent } from './...'; window.ItemComponent = ItemComponent;</script>\n```\n\n### \"Values not updating\"\n\n✅ Use `@change` or `@input`, not `@keyup`:\n\n```html\n<!-- ✅ Good -->\n<input @change=\"setOverride('pax', $event.target.value)\">\n\n<!-- ❌ Bad -->\n<input @keyup=\"setOverride('pax', $event.target.value)\">\n```\n\n### \"Styling looks wrong\"\n\n✅ Make sure Google Fonts load:\n\n```css\n/* Should already be in ItemComponent.html <style> tag */\n@import url('https://fonts.googleapis.com/css2?family=Outfit:wght@400;500;600;700&family=Playfair+Display:wght@600;700&display=swap');\n```\n\n## Next
