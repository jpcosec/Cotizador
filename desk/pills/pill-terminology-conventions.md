## What
Standard mapping between English code terms and Spanish domain terms.

## Why
Reconciles technical logic with the business language of the user.

## Mapping
| Code Term (EN) | Domain Term (ES) | Context |
|----------------|------------------|---------|
| `pax` | Pax / Personas | Number of attendees |
| `item` | Item / Servicio | Catalog entity |
| `basket` | Canasta / Carrito | Current selection |
| `quotation` | Cotización | The final document |
| `client` | Cliente | The company/person |
| `absorbed` | Incluido / Absorbido | Zero-price kit component |
| `unit` | Unidad | Count of items |
| `duration` | Duración | Time in minutes |
